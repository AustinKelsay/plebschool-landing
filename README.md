# pleb.school Landing Page

Marketing landing page for [pleb.school](https://pleb.school) — a forkable, Nostr-native education stack with Lightning payments.

## Stack

- **Next.js 15** with App Router
- **Tailwind CSS 4** with OKLCh color system (matching the default pleb.school theme)
- **TypeScript 5**
- **lucide-react** icons

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # Production build
```
